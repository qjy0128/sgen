# 分拣标签

各工程技能使用五个标准分拣角色。本文件把角色映射到本仓库议题仓库实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签          | 含义                     |
| -------------------------- | ------------------- | ------------------------ |
| `needs-triage`             | `needs-triage`      | 待维护者评估             |
| `needs-info`               | `needs-info`        | 等待报告者补充信息       |
| `ready-for-agent`          | `ready-for-agent`   | 规格完备，可交给 AFK Agent |
| `ready-for-human`          | `ready-for-human`   | 需要人工实现             |
| `wontfix`                  | `wontfix`           | 不予处理                 |

当技能提到某个角色（如"打上 AFK 就绪的分拣标签"），使用上表对应的标签字符串。
